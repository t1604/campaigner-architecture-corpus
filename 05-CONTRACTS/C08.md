Applies
A7 → A8; B4/B5 review boundary and any equivalent one-time review package.


Trigger
Campaign/plan is responsible and understandable enough for user review.


Producer
Director/Advisor + relevant Brand/Creative/Media/Meta/Metrics contributors.


Receiver
User through Advisor/Experience.


Must Carry
Exact version, what will be published, audience/scope meaning, Offer/CTA/destination, budget envelope, time/window, creative/assets, material assumptions/risks/Unknowns, measurement intent, unresolved manageable gaps, and what approval covers.


Must Not Carry / Forbidden
No live Authorization is carried; user is not asked to choose professional mechanics that Campainer owns.


Authority / Receiver Discretion
User may approve/reject/request change. Approval is scoped to the presented package and does not create live Authorization.


Required Output
Approved/rejected/deferred package version with corrections and approval scope.


Semantic Return
Return to the owning Stage when requested change alters strategy, Brand truth, creative meaning, budget, measurement or feasibility.


Evidence / Lineage
Approved/rejected/deferred version + corrections + approval scope.


Invariant
User review makes the proposal understandable and approvable; it does not transfer professional mechanics or execution authority to the user.


Common Envelope
Identity/Scope, Intent/Meaning, Decision Need, minimum-sufficient Local Context, Knowledge/Evidence/Unknowns, Freshness, Authority State, Protected Constraints, Receiver Discretion, Required Output/Return and Lineage apply when relevant. Exact fields/enums/API remain Deferred.


Pilot Human Review
Material professional/execution decisions remain under 100% Human Review according to applicable Stage Truth and pilot policy.
