0. PURPOSE


מסמך זה מבצע Reconciliation ל-Creative Core על בסיס Creative/Graphic P0 Professional Knowledge, Brand reconciliation, Strategy knowledge, Metrics/Measurement, Advisor Core, Director, Meta/Execution boundary ו-Semantic Handoff working principle.


המטרה היא להגדיר מה Creative אחראי להחליט ולשמר, בלי להפוך Format, UGC, Video, Hook או Platform Best Practice ל-Truth.


1. ROLE OF THE CORE


Creative Core מחזיק את הדרך המקצועית שבה Strategic/Marketing intent הופך לייצוג קריאטיבי שנועד לבצע Creative Job מוגדר, בתוך Brand/Truth/Rights/Policy/Platform constraints, וניתן לבדיקה וללמידה.


Creative אינו רק “מייצר מודעה”.
הוא אחראי לבחור ולהרכיב Representation/Concept/Execution שמשרת את השינוי המבוקש אצל הקונה, תוך שמירת המשמעות האסטרטגית.


2. WHAT CREATIVE IS NOT


Creative אינו:
- Strategy Engine;
- Brand Truth authority;
- Meta Media decision maker;
- Sales process owner;
- Metrics truth owner;
- Production vendor itself;
- permission/authority owner;
- universal best-practice library;
- format selector driven only by platform convenience.


3. ROOT CHAIN — CANDIDATE CORE MODEL


A strong Working chain is:


MARKETING PROBLEM / CURRENT BUYER STATE / DESIRED BUYER STATE
+ STRATEGIC INTENT / MUST-BELIEVE / PROOF REQUIREMENT
+ OFFER / NEXT STEP
+ BRAND SNAPSHOT / AVAILABLE ASSETS / RIGHTS
+ PLACEMENT / CONTEXT / PLATFORM CONSTRAINTS
→ CREATIVE JOB
→ REPRESENTATION / MECHANISM CANDIDATES
→ CONCEPT
→ EXECUTION / ASSET / FORMAT
→ VARIANT / TESTABLE CHANGE
→ PROCESSING / STATE-CHANGE EVIDENCE
→ DOWNSTREAM BUSINESS EVIDENCE
→ PRESERVE / REFRESH / REOPEN / WAIT.


Exact fields and sequence remain interface/architecture work.

5. CREATIVE JOB


Creative should know the primary professional job it is trying to perform.


Candidate job families include:
- Attention Entry;
- Relevance Recognition;
- Problem/Situation Clarification;
- Category/Solution Understanding;
- Differentiation/Comparison;
- Belief/Trust Support;
- Risk Reduction/Process Visibility;
- Value/Offer Clarity;
- Self-Selection/Qualification;
- Action Path;
- Memory/Provider Retrievability;
- Expectation Setting;
- Local/Physical Action;
- Re-engagement/State Recall;
- Proof Acquisition Trigger when required evidence does not yet exist.


The CJ01–CJ15 taxonomy is retained as a strong Working ontology, not frozen as a final universal enum.


One asset may support Primary + Secondary Jobs, but piling jobs creates hierarchy/comprehension/measurement risk.


6. JOB BEFORE FORMAT


The governing question is:
What must be represented or processed for this Creative Job to occur?


Format follows representation need and context.


No universal:
- Video > Image;
- UGC > Brand;
- Founder > Customer/Product/Expert;
- short > long;
- fast cuts > slow;
- Reels > Feed;
- animation > static.


Media/format choice is a professional judgment informed by:
- the Job;
- proof/evidence type;
- what must be demonstrated/compared/understood;
- buyer-state/information need;
- available authentic assets;
- Brand constraints;
- placement behavior;
- technical feasibility;
- production cost/value;
- measurement need.


7. ATTENTION / HIERARCHY / COMPOSITION


Attention is necessary for many Jobs but is not sufficient for persuasion/business success.


Creative should structure entry, orientation, allocation and transfer of attention in a way that serves the Job.


Visual hierarchy/composition should prioritize professional information flow, not decoration.


Salience, size, position, contrast, clutter, white space and framing can matter, but there is no universal hierarchy percentage/formula.


8. TYPOGRAPHY / COLOR / LEGIBILITY


Typography and color serve:
- identity;
- hierarchy;
- legibility;
- tone/meaning;
- emphasis;
- accessibility/technical constraints.


No universal serif/sans, “color psychology” or conversion font formula is Core truth.


Brand constraints do not excuse unreadable mobile execution.


Hebrew/RTL mobile and subtitle calibration remains pilot/local testing work.


9. IMAGE / VIDEO / FRAMING / PACING


Image/video/framing/pacing should follow representational and processing requirements.


Cuts can orient attention and also consume processing capacity.
Real-world media can be necessary when the claim itself requires real proof.
Generated media can be useful representation but may not substitute for evidence of real customer/project/outcome.


First-frame and pacing decisions are contextual and testable; no universal cutoff/cadence is promoted.


10. PROOF VISUALIZATION / SOURCE MATCH


Creative translates a Proof Requirement into a representation only after the relevant evidence exists/is usable.


Working chain:
Claim
→ Buyer Question
→ Risk/Trust Object
→ Required Evidence
→ Available Proof
→ Source Properties
→ Visual/Temporal Form
→ Limitations.


Source candidates may include:
Customer/Testimonial / Founder / Expert / Product / Process / Demonstration / Data / Third Party / Institution / Similar Customer / Case.


No universal source ranking exists.


Creative must not fabricate experience, endorsement, result, project, customer or authority merely to satisfy a Proof Job.


11. BRAND FREEDOM / PROTECTED CORE


Creative receives a scoped Brand Snapshot containing protected identity, permitted variation, approved assets/versions, rights, proof and restrictions.


Creative owns real execution freedom inside that frame.


Creative does not need Brand/Advisor approval for every pixel if the change remains within approved freedom.


If the solution requires material change to:
- strategic intent;
- value proposition/offer;
- audience/buyer-state assumption;
- proof claim;
- protected brand truth;
- legal/truth boundary;
then Creative must Semantic Return rather than silently reinterpret.


12. CREATIVE EXPRESSION KNOWLEDGE — NORMALIZATION REQUIREMENT


Before Build, the Professional Knowledge should be normalized into one coherent expression layer covering at least:


Meaning / Creative Job
→ Tone / Voice / Copy Expression
→ Visual Hierarchy / Composition
→ Typography / Color / Legibility
→ Photography / Illustration / Image Representation
→ Video / Framing / Motion / Pacing
→ Audio / Voice / Music / Silence
→ Proof Visualization / Source
→ CTA / Action Path
→ Placement / Native Adaptation
→ Destination Continuity.


This is a normalization/indexing requirement, not a formula that says one upstream state deterministically chooses one execution.


13. PLATFORM-NATIVE ADAPTATION


Platform/placement adaptation should progress conceptually through:
Technical Fit
→ Legibility Fit
→ Behavior Fit
→ Creative Job Fit
→ Measurement Fit.


Resize alone is not native adaptation.


Meta specs/guidance are freshness-dependent Platform Knowledge. Creative decides how to preserve Job within those constraints; Meta does not choose the Job.


14. AD → DESTINATION CONTINUITY


Creative promise, proof, Offer, CTA and expectations should not contradict the next experience.


Destination mismatch can masquerade as Creative failure or “fatigue.”


Before changing a working Creative, check whether the destination/route/response/business state broke continuity.


Destination owner may be another role; Creative raises the mismatch rather than silently changing strategy to compensate.


15. MISSING PROOF / MISSING ASSET ROUTING


MISSING PROOF can be:
- Knowledge Gap: evidence existence/validity unknown;
- Execution Gap: valid proof exists but no usable asset;
- User/Business Action Request: user is best evidence source;
- Wait/Alternative: another truthful proof/representation can serve the Job.


MISSING ASSET can be:
- Knowledge/rights/status gap;
- Production/Execution gap;
- user/business asset request;
- alternative representation;
- defer/wait.


Pseudo-proof is prohibited.


16. CREATIVE DIVERSITY / VARIANTS


A variant should have a reason.


Meaningful variation may change:
- hypothesis/mechanism;
- angle/hook;
- proof/source;
- representation;
- format/placement;
- sequencing;
- CTA/surface expression.


Cosmetic variation may still have production/placement purpose, but should not be mislabeled as testing a different hypothesis.


No fixed number of variants is promoted.


17. FATIGUE / REFRESH


Observed deterioration does not prove Creative fatigue.


Before refresh, inspect relevant alternatives:
Data/Measurement
→ Delivery/Audience/Auction
→ Offer/Price/Availability
→ Destination/Route/Response
→ Repeated Exposure
→ Creative Component
→ Season/Brand relevance.


Only when a plausible Creative-specific mechanism exists should refresh target that surface.


No universal frequency/fatigue cutoff or refresh cadence.


18. PRESERVE WHAT WORKS


Creative is not rewarded for continuous novelty.


Possible states:
- PRESERVE CANDIDATE;
- PRESERVE IN SCOPE;
- PRESERVE CORE / VARY SURFACE;
- REOPEN.


Preserve a supported message/proof/representation when change lacks evidence.


Refreshing only a suspected surface is often better than rebuilding the whole concept and destroying the learning baseline.


19. CREATIVE TESTING / MEASUREMENT


TEST QUESTION ≠ VARIANT ≠ METRIC ≠ DECISION.


A Creative test should preserve:
- Decision Ref;
- Business/Offering;
- Marketing Problem/Buyer State;
- Primary Job;
- hypothesis/mechanism;
- control/treatment/what changed;
- placement/audience/route;
- primary Job-aligned indicator;
- downstream guardrail;
- outcome maturity;
- alternative explanations;
- confidence;
- preserve/reopen;
- transfer scope.


Metrics owns measurement truth and causal interpretation.
Creative owns what Job/mechanism the test was intended to evaluate.


20. CAUSAL GUARDRAILS


Correlation ≠ Creative causation.
Result after change ≠ result caused by Creative.
Meta delivery may route variants to different audiences/exposures.
Offer/price/season/destination/sales treatment can change simultaneously.
Multiple Creative changes reduce mechanism identifiability.
Winner’s curse/noise/repeated testing can exaggerate winners.


CTR/view time alone cannot establish success when the Job is comprehension, qualification, expectation setting or business progression.


21. RIGHTS / CONSENT / PROVENANCE / TRUTH


Creative may use only assets/claims whose intended use is sufficiently authorized for the relevant scope.


It must preserve the distinction between:
- real proof;
- illustrative/generated representation;
- edited derivative;
- testimonial/endorsement;
- licensed/stock media;
- customer/company data/screenshots.


Exact legal treatment is jurisdiction/sector dependent.
Platform approval is not legal/truth clearance.


22. AI-GENERATED / AI-EDITED ASSETS


AI can be a production/representation tool, not an authority to invent Brand Truth or proof.


Internal lineage should distinguish generated/edited ingredients sufficiently to support:
- truthfulness;
- rights/provenance review;
- platform disclosure requirements;
- future correction/removal.


OWNER PRINCIPLE RESOLVED BY D07: generated/edited state must be tracked sufficiently to distinguish it from real evidence and support rights/truth/platform disclosure; generated evidence-like media may never masquerade as real proof. Exact labeling schema/threshold remains Brand/Legal/Meta/Build work.


23. PRODUCTION / SUBCONTRACTOR BOUNDARY


Creative converts Creative Intent/Concept into a production-usable semantic package.


Production specialist owns craft/execution inside that package.


A pilot-minimum package should be able to preserve:
- Creative Job;
- concept/representation intent;
- must-preserve meaning;
- proof/source and truth restrictions;
- protected Brand elements;
- assets/source masters;
- rights/consent constraints;
- output/placement needs;
- permitted substitutions;
- quality/acceptance meaning;
- return conditions.


Production cannot change meaning/claim/Strategy to solve craft convenience.


D02 OWNER APPROVED the Creative↔Production working contract as a derivation basis on 2026-08-18. Exact final schema remains open and must be normalized before Build.


24. ADVISOR / STRATEGY ↔ CREATIVE BOUNDARY


Advisor/Strategy provides professional/strategic meaning; Creative owns its execution form.


Pilot-minimum upstream contract should be able to convey:
- Business/Offering/current goal;
- Marketing Problem/Bottleneck;
- current/desired Buyer State where relevant;
- strategic intent;
- Primary Message/Creative Job or job requirement;
- Must Believe / Buyer Question;
- proof requirement/evidence/limitations;
- Offer/Next Step;
- critical Unknowns;
- Brand Snapshot;
- platform/placement constraints if already known;
- measurement hypothesis/guardrails;
- protected constraints vs creative freedom;
- return conditions.


No requirement that every item becomes a mandatory field in every case.


Advisor must understand enough Creative decision structure to provide a usable package but must not design pixels/shots by default.
Creative must understand enough Strategy to recognize when an execution choice would alter strategic meaning.


25. USER / BUSINESS AS CREATIVE INPUT SOURCE


Creative/Advisor may request real evidence/assets when they materially improve the Job:
- project/product/process photos/videos;
- demonstrations;
- customer stories/testimonials;
- credentials/documents/data;
- founder/team/expert explanation when source fits;
- permissions/releases.


Every request should be specific, justified, minimum useful, rights-aware, and explain what it enables.


The user is not tasked simply because Studio wants richer content.


26. TRANSFERABILITY


Cross-business Creative learning can generate a Prior/Test Candidate only.


Transfer fit should consider at least:
Marketing Problem / Buyer State / Offering / Proof Requirement / risk/involvement / Journey/CTA / placement / audience familiarity / Brand constraints / destination / measurement semantics.


A winning Hook/Format/Source from another client is not Local Truth.


27. FRESHNESS


High freshness:
Meta specs/placements/safe zones/audio/features/GenAI/policy/music/testing capabilities.
Jurisdiction/sector legal constraints before sensitive use.


Local reopen:
Offering/Brand/site/route/sales process/audience changes.


Foundational perception mechanisms are slower-changing but remain reopenable on stronger evidence.


28. DO-NOT-PROMOTE


Do not promote:
- Video always wins;
- UGC inherently authentic/better;
- Founder always builds trust;
- three-second universal law;
- more/faster cuts better;
- CTR/watch time = Creative success;
- fixed frequency = fatigue;
- fixed variant count;
- universal font/color/CTA/hierarchy formula;
- reviews/testimonials mandatory;
- generated project image as real portfolio proof;
- resize = placement adaptation;
- positive post-change result = proof of Creative mechanism;
- cross-business winner = local rule;
- Meta recommendation = Creative Truth;
- platform approval = truth/legal safety.
