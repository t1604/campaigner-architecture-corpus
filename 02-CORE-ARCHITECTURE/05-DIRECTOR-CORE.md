0. PURPOSE


מסמך זה הוא Wave A Truth/Core Reconciliation עבור Director. הוא נשען על CAMPAINER-CONSTITUTION-001 v1.1, CAMPAINER-PRODUCT-TRUTH-CORE-001 v1.2, CAMPAINER-ADVISOR-CORE-001 v1.1, DIRECTOR-CONTEXT-BRIEF-001-DRAFT, GOV-DIRECTOR-MOMENT-BENCHMARK lineage, Professional Knowledge Foundation, Master Development Path-002, ו-WORKING-SEMANTIC-HANDOFF-AND-ADJACENT-ROLE-LITERACY-001.


המסמך אינו מקדם אמת קנונית אוטומטית ואינו קובע Runtime orchestration.


1. ROLE OF THE CORE


Director מחזיק את תחום ההכרעה של הרגע.


תפקידו הוא להפוך:
- מטרת משתמש/עסק;
- Context מקומי מורשה;
- Knowledge/Evidence רלוונטי;
- Golden Lead truth/constraints;
- Metrics/Measurement state;
- Platform possibility/constraints;
- open gaps/contradictions;


למסגרת החלטה מקצועית תחומה:
מה צריך להחליט עכשיו, מה האפשרויות האמיתיות, מה ידוע/לא ידוע, מה הטרייד-אופים, מה חוסם, מה ניתן להתחיל, מה דורש אישור, ומה צריך לעבור הלאה לבעל התפקיד המתאים.


Director אינו האיש שהמשתמש פוגש. Advisor הוא הישות המקצועית הרציפה מול המשתמש.


2. WHAT DIRECTOR IS NOT


Director אינו:
- Complete User Context;
- Knowledge/Evidence;
- Advisor persona/relationship;
- Creative Director;
- Media buyer;
- Meta execution engine;
- Orchestrator;
- Task engine;
- Metrics calculator;
- Learning promotion engine;
- God Object שמחזיק את כל התיק ואת כל המקצועות.


הוא אינו רשאי להמציא עובדה כדי לקבל החלטה ואינו רשאי להרחיב סמכות כי “צריך להתקדם”.


3. ROOT DISTINCTION — KNOW ≠ CHOOSE ≠ EXECUTE


KNOW:
Knowledge/Evidence + Complete User Context + Metrics/Platform truth מספקים את מה שידוע, לא ידוע, סותר, אפשרי ומוגבל.


CHOOSE:
Director מחזיק את מסגרת ההכרעה: איזה Decision Need קיים עכשיו, מה החלופות, מה הסיכונים, מה חסר, ומה הכיוון המקצועי המועמד.


ADVISE / EXPLAIN:
Advisor מפעיל שיקול דעת מקצועי, ממליץ ומסביר למשתמש בתוך זהותו ואחריותו.


EXECUTE:
Execution/Orchestration מממשים רק פעולה מורשית, בלי לשנות את הכוונה המקצועית בשקט.


Core principle:
Knowledge does not decide because it knows. Director does not fabricate because it must choose. Execution does not redesign because it can execute.


4. THE ACTIVE MOMENT


Director operates on a bounded decision moment, not on the entire life of the user at once.


A moment exists when something materially requires interpretation/choice, for example:
- user request;
- new evidence;
- material state change;
- scheduled/reopen trigger;
- campaign result;
- business intervention outcome;
- contradiction;
- execution feasibility failure;
- material risk;
- open decision reaching maturity.


The exact technical moment model is Architecture, not Core truth.


5. MINIMUM SUFFICIENT CONTEXT


Director should receive a moment-specific projection, not full-file access by default.


The projection must be sufficient to decide responsibly and may expand only when needed.


Candidate content:
- active subject/business/offering/account;
- current user/business goal;
- decision required now;
- material local facts;
- applicable professional knowledge;
- evidence and confidence;
- key unknowns/contradictions;
- Golden Lead / business-outcome implications;
- capacity/economics/serviceability constraints;
- permissions/authority state;
- platform feasibility state;
- current measurement state;
- commitments/open obligations;
- relevant baseline/change history.


Exact payload is not canonical here.


6. DECISION OBJECT


A material Director decision should be able to express conceptually:
- decision question;
- objective / desired state;
- current state;
- relevant bottleneck/problem/opportunity;
- candidates;
- evidence for;
- evidence against;
- unknowns;
- breakers / hard constraints;
- trade-offs;
- confidence / uncertainty;
- recommended next professional path;
- what would change the decision;
- authority/approval needed;
- downstream consumer/role;
- return conditions.


This is a semantic contract, not a final schema.


7. PROFESSIONAL PROBLEM BEFORE SOLUTION


Director must not start with a tool, platform capability, asset or tactic and backfill a reason.


For marketing decisions, the professional chain should preserve:
BUSINESS / OFFERING / CUSTOMER-ACCOUNT / BUYING SITUATION
→ CURRENT STATE
→ DESIRED STATE
→ MARKETING PROBLEM / BOTTLENECK / OPPORTUNITY
→ STRATEGY CANDIDATES
→ EVIDENCE FOR / AGAINST / UNKNOWNS
→ DECISION
→ TRANSLATION TO ROLE.


Marketing Problem/Bottleneck is an OWNER-APPROVED principle in Director decisioning (A02, 2026-08-18). Exact object/schema remains deferred.


8. ADAPTIVE DEPTH


Director should decide at the depth required by the decision, not force every situation through the same analysis depth.


More uncertainty, irreversibility, cost, legal/privacy risk, business impact or conflicting evidence may require deeper evidence and more explicit comparison.


Low-impact/reversible decisions may use a lighter decision path.


No fixed global threshold is promoted here.


9. NO FALSE DEAD END


When information/capability/asset is missing, Director distinguishes at least conceptually:
- START NOW;
- START AND COMPLETE IN PARALLEL;
- START WITH RESPONSIBLE ALTERNATIVE;
- WAIT / MONITOR;
- DO NOTHING / PRESERVE;
- STOP because no responsible route exists.


The missing item must be evaluated by its actual decision impact.


Ordinary missing information or asset does not automatically become a hard stop.


10. DECISION UNDER UNCERTAINTY


Director may recommend a path while uncertainty remains, if the remaining uncertainty is visible and manageable relative to the decision.


It should know:
- which uncertainty is decision-relevant;
- what could change the recommendation;
- what can be learned later;
- what must be known before action;
- what can remain Unknown without causing irresponsible execution.


This is essential to Progressive Diagnosis and first-campaign readiness.


11. AUTHORITY / CHOICE / APPROVAL BOUNDARY


Director frames and chooses professional direction; it does not convert that direction into user permission.


Understanding → Recommendation → Choice → Approval → Authorization → Execution remain separate states inherited from the Constitution.


Director decision does not silently imply:
- budget approval;
- launch approval;
- asset approval;
- data-access permission;
- external write permission;
- consent for material business intervention.


Exact authority contracts remain downstream architecture.


12. RELATION TO ADVISOR


Director is not a second professional persona.


Advisor:
- owns professional relationship with user;
- understands/explains/recommends;
- can challenge or return a contradiction;
- must be able to justify what it presents.


Director:
- owns the decision-state frame;
- ensures relevant alternatives/unknowns/tradeoffs are considered;
- supplies a bounded Decision Contract.


If Advisor cannot professionally justify a supplied decision because of conflicting Context/Knowledge/Evidence, it must return the contradiction; it does not silently rewrite the decision.


13. RELATION TO COMPLETE USER CONTEXT


Complete User Context owns local truth/history.
Director receives a decision projection.


Director must not become the storage home for user profile, local facts or historical state.


It can request deeper evidence/context only when the current decision requires it.


14. RELATION TO KNOWLEDGE / EVIDENCE


Knowledge/Evidence supplies:
- applicable knowledge;
- claim status;
- evidence;
- scope;
- confidence/maturity;
- contradictions;
- open gaps;
- freshness;
- prohibited inference.


Director decides what these mean for the current decision; it does not promote Knowledge Items or alter their epistemic status to support its preferred answer.


15. RELATION TO GOLDEN LEAD


Golden Lead supplies the multidimensional business-value compass.


Director uses it to prevent local optimization from winning over the business objective.


Director must keep separate, where relevant:
- Desired/Customer Value;
- Potential Lead Quality;
- Baseline Outcome Propensity;
- Incremental Marketing Opportunity;
- Access/Retrievability Need;
- Business Realization Capability;
- Realized Outcome;
- Confidence.


No global score may silently collapse these objects.


Exact Golden Lead truth remains the Golden Lead Core’s responsibility.


16. RELATION TO METRICS / MEASUREMENT


Metrics tells Director what was measured, where, when, with what coverage, maturity and causal limits.


Director may use measurement to revise decisions, but it may not turn observed change into causal explanation without sufficient design.


Baseline Snapshot, intervention/change history and concurrent changes must be available when relevant to avoid false attribution.


17. RELATION TO META / TECHNICAL


Before strategy, Meta/Technical may provide a Capability/Constraint/Possibility View:
- AVAILABLE NOW;
- ENABLEABLE;
- CONDITIONAL;
- REQUIRES LIVE CHECK;
- BLOCKED.


Director uses this to understand feasibility — not to derive strategy from platform convenience.


After professional decision:
Director/Advisor send professional intent downstream.
If execution is not faithful/possible, Technical returns reason + alternatives.
It does not substitute its own strategy.


18. SEMANTIC HANDOFF — CANDIDATE CROSS-CUTTING TRUTH


Every material Director handoff should preserve enough meaning for the receiving professional role to act without guessing.


Candidate semantic content:
- Intent;
- Meaning / why;
- relevant Context;
- Evidence;
- Uncertainty;
- Authority state;
- Constraints;
- Permitted professional freedom;
- Return Conditions.


Minimum Sufficient Package does not mean “few fields.”
It means the minimum package that lets the receiver preserve the professional meaning while exercising its own expertise.


19. ADJACENT-ROLE LITERACY


Director should know the decision needs and input/output boundaries of adjacent professional roles sufficiently to route a usable handoff.


This does not mean Director owns those professions.


Deep own-domain competence + bounded adjacent-role literacy is an OWNER-APPROVED cross-cutting principle (A10, 2026-08-18).


20. SEMANTIC RETURN / NO SHADOW DECISION


If the receiving role cannot realize the intent without materially changing meaning, objective, scope, evidence assumptions, risk, authority or expected outcome, it must return the issue.


Return should be able to state:
- what was understood;
- what cannot be realized faithfully;
- why;
- what is missing;
- alternatives;
- which alternative preserves meaning;
- which alternative changes strategy/intent;
- who must decide.


A returned handoff is a valid professional result, not failure.


21. DECISION HISTORY / TRACEABILITY


For material decisions Campainer should be able to trace:
Purpose / Goal
→ Applicable Truth / Knowledge
→ Local Context / Evidence
→ Decision
→ Advisor Recommendation / User Choice
→ Authorization
→ Execution
→ Measurement
→ Learning / Next Decision.


Director owns the decision segment of this lineage, not all segments.


22. DECISION REVISION


A decision can be reopened when:
- user goal changes;
- local truth changes;
- new evidence contradicts the basis;
- relevant knowledge is demoted/reopened;
- platform feasibility changes;
- measurement matures;
- business capacity/economics change;
- execution failure reveals non-equivalence;
- risk/authority conditions change.


Revision must preserve why the previous decision was made and why it changed.


23. PRESERVE / WAIT / DO NOTHING


Director should not be biased toward intervention.


PRESERVE, WAIT, MONITOR and DO NOTHING can be professional decisions when:
- evidence supports current behavior;
- change risk exceeds evidence-backed benefit;
- outcome is immature;
- intervention would confound learning;
- no relevant decision exists yet.


This must not become inactivity theater; the reason and reopen trigger should be explicit where material.


24. USER/BUSINESS INTERVENTION BOUNDARY


Director may identify a business-side intervention candidate when there is a clear contribution path to Golden Lead/business outcome, such as:
- lead-handling improvement;
- response/follow-up process;
- qualification;
- measurement/CRM improvement;
- proof/asset creation;
- capacity/serviceability action;
- offer/process change.


Director does not automatically authorize or execute the intervention.
Authority and domain competence remain separate.


25. DO-NOT-PROMOTE


Do not promote into Director Core:
- fixed list/count of decision families solely because older architecture used them;
- fixed decision score/weight/threshold;
- full-file access;
- tool/API selection mechanics;
- Orchestrator runtime state machines;
- Meta tactic as strategy truth;
- creative execution mechanics;
- exact dashboard/UI;
- fixed question count;
- automatic user authorization;
- Shadow Decision;
- assumption that every detected problem requires action.

27. RECONCILIATION DISPOSITION


KEEP / CORE CANDIDATE:
- bounded decision responsibility;
- KNOW≠CHOOSE≠EXECUTE;
- moment-specific decision framing;
- minimum sufficient context;
- alternatives + evidence for/against + unknowns;
- authority separation;
- uncertainty management;
- no false dead end;
- no shadow decision;
- reopen/change lineage;
- preserve/wait/do-nothing as valid decision classes;
- local optimization subordinate to Golden Lead/business outcome.

- Semantic Handoff;
- Semantic Return;
- Adjacent-role literacy;
- Progressive Diagnosis stop logic through decision-relevant unknowns;
- Baseline/concurrent-change awareness in decision interpretation.

- exact moment taxonomy;
- exact Director/Advisor disagreement protocol;

- fixed universal decision scores;

- automatic action on detection;
- hidden overwrite of professional intent;
- full context distribution to all roles.
